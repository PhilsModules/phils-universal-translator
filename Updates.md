# Changelog & Updates: Phil's Universal AI Translator

All notable changes and version milestones for the module will be documented here.

## [1.0.0] - 2026-08-26 (English)
### 🚀 Initial Release (Foundry VTT v14 Ready)
- **🌍 True Multilingual Translation (Any Language ➔ Any Language)**: Fully flexible translation between any language pair supported by your AI (e.g., English ➔ German, French, Spanish, Italian, Portuguese, Polish, Ukrainian, Japanese, Chinese, Russian, or German ➔ English, etc.).
- **🌐 100% Universal & System-Agnostic**: Completely decoupled from specific game systems; compatible with any system on Foundry VTT (Pathfinder 2e, D&D 5e, Shadowrun, Call of Cthulhu, Crucible, Cyberpunk, Alien, Tormenta20, Savage Worlds, etc.).
- **🎭 Dynamic AI Prompts & Setting Profiles**: Automatic system detection with selectable genre presets (Fantasy, Grimdark, Sci-Fi, Cyberpunk, Horror, Modern, Post-Apocalyptic, Custom).
- **📚 12-Category Lore Glossary**: Automatically generates and maintains an in-world journal (*AI Glossar*) with automated category classification and alphabetical sorting.
- **🛡️ Universal Core Starter Glossary**: Pre-packaged with over 100 common TTRPG terms, conditions, equipment, and rules concepts.
- **⚡ 4-Step Translation Studio (ApplicationV2)**:
  - Drag & Drop for journals, items, actors, folders, and compendium packs.
  - Real-time live capacity meter with automated text batching.
  - 1-Click prompt copying & direct AI opening (Gemini, ChatGPT, Claude, Copilot, Perplexity).
  - Resilient JSON parser with automatic encoding and Mojibake repair.
  - Side-by-side rich diff preview with new glossary terms approval.
- **📢 Narrative Read-Aloud (📢)**: Red bullhorn icon in window headers and floating text-selection widget for instant GM translations at the virtual table.
- **🔍 Campaign Integrity Auditor**: World-wide scan for missing chunks, dead links, and encoding glitches with 1-click automated repairs.
- **🔄 Non-Destructive Runtime Overlay**: Seamlessly toggle between translations and original text in sheet headers.
- **🔗 Smart Link Remapper**: Automatically updates compendium links (@UUID/@Embed) to matching imported world documents.
- **🔎 Global Fulltext Journal Search**: Search and replace across all journals with RegEx support.
- **💾 Translation Memory & Statistics**: Persistent world translation store with JSON export/import and hours-saved metrics.
