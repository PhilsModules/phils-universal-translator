Phil's Universal AI Translator

Universal, multilingual AI translation for any tabletop RPG system in Foundry VTT.

Phil's Universal AI Translator provides game masters with a structured, reliable way to translate adventure modules, journals, items, actors, folders, and compendium packs into any language directly inside Foundry VTT without recurring API costs.

Key Features

  • True Multilingual Translation
    Translate content between any language pair supported by your chosen AI model, including English, German, French, Spanish, Italian, Portuguese, Polish, Ukrainian, Japanese, and Chinese.
  • System-Agnostic Engine
    Operates seamlessly with any game system in Foundry VTT, including Pathfinder 2e, D&D 5e, Shadowrun, Call of Cthulhu, Crucible, Cyberpunk, Alien, Tormenta20, Savage Worlds, or custom homebrew systems.
  • Foundry v14 Ready
    Engineered using modern ApplicationV2 foundations with verified compatibility spanning Foundry v12, v13, and v14.
  • LinkProtection Protocol
    Guarantees that internal Foundry entity links (@UUID, @Embed, @Check, @Damage), inline roll formulas, and HTML structures are preserved without corruption.
  • 12-Category In-World Lore Glossary
    Automatically builds and updates a dedicated journal (AI Glossar) categorized into locations, characters, deities, factions, biomes, species, cultures, classes, items, rules, and languages to maintain long-term naming consistency.
  • Campaign Integrity Auditor
    Scans world documents for broken entity links, missing text blocks, and character encoding issues, offering one-click batch repairs.
  • Non-Destructive Runtime Overlay
    Toggle between translated text and original source content directly in document sheets without altering underlying database files.
  • Narrative Read-Aloud Tool
    Trigger on-the-fly translations directly from window headers or via a floating text selection tool for instant narration during live sessions.
  • Translation Memory & Smart-Sync
    Stores translations locally and re-applies them automatically when official adventure modules or game systems receive updates.
  • Automatic Safety Backups
    Generates an immutable duplicate of every document before changes are written, allowing any update to be reverted instantly.

How It Works

  • 1. Select Content: Drag and drop any journal, item, actor, folder, or compendium pack into the Translation Studio.
  • 2. Copy Structured Prompt: Click a single button to copy the optimized prompt and launch your preferred web AI (Gemini, ChatGPT, Claude, Copilot, Perplexity).
  • 3. Paste & Validate: Paste the generated JSON response back into the studio. The parser automatically validates syntax, heals character encoding, and checks link integrity.
  • 4. Preview & Apply: Inspect changes in the side-by-side diff viewer, review newly detected glossary terms, and apply updates to your world.
